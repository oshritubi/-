# /site-report

1. Read `projects/index.md`.
2. For each active project, read its newest supervision log entry (including its `## Watch` and
   `## Messages` lines) and its state file. If the state file is newer than your last inspection,
   or `[progress]` notes arrived since then, say so: the contractor did work you have not checked.
3. Report in the owner's language, one short block per project:
   - **State** in one line.
   - **Waiting on you:** decisions or questions the owner owes, if any.
   - **Not checked yet:** work delivered since the last inspection, if any, including a `[done]`
     message not inspected yet.
   - **Link:** direct or paste, and the mode, in a few words. Mention it only if it changed or
     something is stuck (a message that got no reaction).
4. End with one line: what you recommend the owner does first.

No tables unless the owner likes them (see `me/profile.md`). Keep it short enough to read on a
phone.
