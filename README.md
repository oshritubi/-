# ערכת המפקח

ערכה שהופכת את Claude Code לשותף פתרונות לעסק — גם אם אתם לא מתכנתים.

## הרעיון בקצרה

מי שבנה פעם בית מכיר את זה: יש **קבלן** שבונה, ויש **מפקח בנייה** שעובד בשבילכם.

עם Claude Code זה אותו מבנה:

1. **הקבלן** — סוכן Claude Code שיושב בתיקיית הפרויקט ובונה.
2. **המפקח** — אותו Claude, בתיקייה הזו. מכיר אתכם, את העסק ואת מה שכבר החלטתם.
3. **אתם** — המנכ"לים. מדברים רק עם המפקח, וכל החלטה נשארת שלכם.

המפקח:
- כותב לקבלן בריף מדויק.
- מתרגם לכם כל שאלה של הקבלן לשפה פשוטה, עם אפשרויות והמלצה.
- בודק כל תכנית לפני שאתם מאשרים.
- בודק כל שלב אחרי שהקבלן סיים.
- אומר לכם איפה כל פרויקט עומד ומה מחכה לכם.

## איך מתחילים

1. מורידים את התיקייה הזו למחשב.
2. פותחים אותה באפליקציית הדסקטופ של Claude Code (או בכל סוכן שעובד על תיקיות).
3. כותבים לו: **"בוא נתחיל — קרא את README + SETUP"**.
4. עונים על כמה שאלות (בערך עשר דקות), ומחברים את הפרויקט הראשון.

אין התקנות ואין חשבונות חדשים — רק קבצי טקסט.

רוצים להבין את השיטה לעומק? קראו את [המדריך הכתוב](GUIDE.md).

## שגרת עבודה

```
אתם  →  המפקח: "אני רוצה אוטומציה ש..."
המפקח →  שואל שאלות הבהרה, כותב בריף
אתם  →  מעבירים את הבריף לקבלן (חלון Claude Code נפרד בתיקיית הפרויקט)
הקבלן →  שואל / מציג תכנית
אתם  →  מדביקים למפקח. מקבלים תרגום + המלצה. מחליטים.
הקבלן →  "סיימתי"
אתם  →  "תבדוק" למפקח. מקבלים ✅ / ⚠️ / ❌
```
